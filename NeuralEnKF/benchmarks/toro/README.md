# Toro Shock Tube

This directory provides a clean Toro shock tube simulation case.

Two simulation workflows are included:

- **initial_run** – simulation starting from time *t = 0*
- **restart_run** – simulation starting from a user-defined initial condition

The restart workflow is required for each data assimilation (DA) cycle.

---

## Directory Structure

```text
toro/
├── initial_run/
│   ├── Allrun
│   ├── input.st
│   ├── plot_final_solution.py
│   ├── figures/
│   └── results/
│
└── restart_run/
    ├── Allrun
    ├── input.st
    ├── plot_final_solution.py
    ├── figures/
    ├── results/
    └── IC/
        ├── CMakeLists.txt
        ├── UserDefinedState.cpp
        └── solution_0000.vtr
```

- **initial_run**  
  Runs the simulation starting from time *t = 0*.

- **restart_run**  
  Demonstrates restarting the simulation from a prescribed initial condition.

- **IC/**  
  Contains the code and input state used to generate the restart initial condition.

- **solution_0000.vtr**  
  Example VTR file used to construct the restart initial condition.  
  Users may replace this file with any VTR file representing the desired restart state.

- **results/**  
  Directory where simulation outputs are written.

- **figures/**  
  Directory where figures generated by `plot_final_solution.py` are saved.

- **plot_final_solution.py**  
  Plots the density, velocity, and pressure fields from the final simulation output.

---

## Running the simulation from time *t = 0*

Navigate to the `initial_run` directory and run

```bash
./Allrun input.st
```

Simulation outputs will be written to the `results/` directory.

To visualize the final solution, run

```bash
python plot_final_solution.py
```

The resulting figure will be saved in the `figures/` directory.

---

## Running the simulation from a user-defined initial condition

First generate the restart initial condition.

Navigate to the `IC` directory:

```bash
cd restart_run/IC
```

Build the restart-state generator:

```bash
cmake .
make
```

After generating the restart state, return to the `restart_run` directory and run

```bash
./Allrun input.st
```

Simulation outputs will be written to the `results/` directory.

To visualize the final solution, run

```bash
python plot_final_solution.py
```

The resulting figure will be saved in the `figures/` directory.

---

## Notes

- The restart workflow demonstrates how the Toro shock tube simulation can be initialized from a prescribed state.
- In the restart example, `solution_0000.vtr` is used as the input state.
- `initial_run` and `restart_run` should produce the same numerical solution for the provided example.
- Simulation outputs are written to the `results/` directory.
- Generated figures are written to the `figures/` directory.
